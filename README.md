# Gayatri Mantra — The Universal Prayer of Light and Wisdom

An interactive, single-file exploration of the Gayatri Mantra (Ṛgveda 3.62.10).

**Live site → https://dennysonkusale-png.github.io/gayatri-mantra/**

## What's inside

- The full mantra in Devanagari with IAST romanisation
- Four languages — English, हिन्दी, मराठी, संस्कृतम् — switching without a page reload
- Dark and light themes, remembered between visits
- The science of vibration: effects on humans and on nature, with an honest note on what the
  research does and does not support
- All twenty-four aksharas of the Gāyatrī metre, each with its bīja, attribute and place of resonance
- A japa counter — 108 per mala, a floating count button on every screen, saved on your device
- A daily practice sequence and a synthesised ambient tone (no audio files are bundled)

## Run it

Open `index.html` in any browser. No build step and no dependencies. The page is complete
without JavaScript — every section, syllable and translation is in the HTML itself; the script
only adds language switching, the theme toggle and the counters. The one external request is
Google Fonts; without it the page falls back to system Devanagari fonts.
